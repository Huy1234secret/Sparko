Notes:

- Ponytail and Ultracave are byte-identical copies of the upstream folders plus the license files.
- UI UX Pro Max is the CLI's output, unmodified. The CLI also installs companion skills (`banner-design`, `brand`, `design`, `design-system`, `slides`, `ui-styling`); they were not requested, `ui-ux-pro-max` does not use them, and they are not vendored. Re-running the CLI adds them back, so delete them afterwards.
- `ui-ux-pro-max/scripts/search.py` needs Python 3 (standard library only). Verify with `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "dashboard" --design-system -p Sparko` and `python3 .claude/skills/ui-ux-pro-max/scripts/validate_data.py`. Two bundled tests (`test_catalog_refresh`, `test_relevance_evaluator`) need upstream repository scripts and do not run here.
